# Smart Fridge & Chef Planner

**Умный Холодильник & Шеф-Планер** — Flutter-приложение, которое решает две
боли сразу: трекинг сроков годности продуктов (сканирование штрих-кодов и
чеков + пуш за 1–2 дня до конца срока) и автоматическую генерацию
персонального меню на неделю из того, что уже лежит в холодильнике, с учётом
калоража, БЖУ, аллергий, диет и сезонности региона. Меню и все данные —
целиком на устройстве. Android · iOS · offline-first · без аналитики,
серверов и аккаунтов.

**Статус:** активная разработка, v0.1.0. Релиз идёт поэтапно по ТЗ:
Шаг 1 (архитектура + база данных) — готов; Шаги 2–3 — после подтверждения.
Детали — [CHANGELOG.md](CHANGELOG.md).

## Как это работает

| Этап | Что происходит |
| --- | --- |
| Онбординг профиля (один раз) | Суточный калораж и БЖУ → аллергии → диета (веган, пост, вегетарианское, низкоуглеводное) → регион (сезонность продуктов) → число приёмов пищи в день |
| Учёт продуктов | Штрих-код сканируется камерой — название, категория и БЖУ подтягиваются из открытой базы Open Food Facts; либо быстрый ручной ввод с типовым сроком хранения по категории. Каждому продукту — дата истечения |
| Напоминания | Локальные уведомления за 2 и за 1 день до конца срока (работают офлайн, восстанавливаются после перезагрузки) |
| Суперпланер (кнопка раз в неделю) | Сначала съесть то, что портится → сверка с калоражем/БЖУ/аллергиями/диетой → учёт сезонности региона. На выходе: меню на 7 дней по приёмам пищи, пошаговые рецепты, суммы БЖУ по дням, список недостающих ингредиентов |
| Покупки | Недостающие ингредиенты плана собираются в чек-лист, из него же — быстрый ввод в холодильник |

## Ключевые возможности

* **Offline-first и приватность** — база SQLite и генерация меню целиком на
  устройстве; единственная сеть — открытый API Open Food Facts по вашему
  штрих-коду; без аналитики, аккаунтов и серверов; облачные резервные копии
  Google отключены (`allowBackup=false`).
* **Цветовая индикация свежести** — зелёный / жёлтый (≤ 2 дней) / красный на
  экране «Мой холодильник»; продукты отсортированы по сроку — что съесть
  первым, видно сразу.
* **Локальный AI без ключей** — планер работает через детерминированный
  офлайн-планировщик на встроенной базе рецептов; опционально подключается
  локальная модель Gemma (MediaPipe, ~1.5 ГБ, скачивается в настройках) для
  живых текстов рецептов. Аллергии и диеты фильтрует слой валидации, а не
  модель — «отравить» меню некорректным ответом LLM нельзя.
* **Сканер двух типов** — штрих-коды (mobile_scanner + Open Food Facts) и
  OCR чеков (ML Kit, распознавание на устройстве, изображение никуда не
  отправляется).
* **Пуши за 1–2 дня до срока** — локальные уведомления, канал
  `expiry_warnings`, пересоздаются при изменении продукта и после
  перезагрузки устройства.
* **RU + EN** — весь интерфейс на двух языках, выбор «системный / русский /
  english»; светлая, тёмная и системная темы Material 3.

## Сборка из исходников

Требуется [Flutter](https://docs.flutter.dev/get-started/install) stable.

```bash
# 1. Клонировать
git clone https://github.com/rvmxl/smart-fridge-chef.git
cd smart-fridge-chef

# 2. Зависимости и локализация
flutter pub get
flutter gen-l10n

# 3. Запуск на устройстве/эмуляторе
flutter run

# 4. Юнит-тесты (реальная SQLite, эмулятор не нужен)
flutter test

# 5. Анализ
flutter analyze --fatal-infos
```

Платформы: Android 8.0+ (API 26), iOS 13+. Разрешения запрашиваются по
мере появления соответствующих шагов: `CAMERA` — сканер (Шаг 3),
`POST_NOTIFICATIONS` — напоминания о сроках (Шаг 3, Android 13+).

## Приватность и разрешения

Приложение не имеет аналитики, рекламы, серверов и аккаунтов: всё хранится
только в приватной папке приложения; облачные резервные копии Google
отключены (`allowBackup=false`, данные не покидают устройство — включая
перенос через Google).

| Разрешение | Зачем |
| --- | --- |
| `INTERNET` | Единственный сетевой вызов — открытый API Open Food Facts по штрих-коду, по действию пользователя. Персональные данные не передаются |
| `CAMERA` (Шаг 3) | Сканер штрих-кодов и фотографирование чеков; OCR выполняется на устройстве (ML Kit), изображение никуда не отправляется |
| `POST_NOTIFICATIONS` (Шаг 3) | Локальные уведомления «срок истекает» за 1–2 дня |
